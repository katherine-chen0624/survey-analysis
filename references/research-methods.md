# 用研方法论参考文档

本文档为 Step 6 AI分析输出提供方法论支撑，包含四个框架：
1. 主题分析方法（用于开放题/Other填答归纳）
2. 定量数据解读框架（用于关键洞察摘要）
3. 用户画像提炼方法（用于用户分层洞察）
4. 定性定量融合方法（用于量表+开放题联合解读）

---

## 一、主题分析方法（开放题归纳）

适用场景：填空题、Other__填答内容归纳

### 执行步骤

**Step 1：通读所有文本，不预设分类框架**
先完整阅读所有有效回答，建立整体感知，不要急于分类。

**Step 2：逐条打标签**
对每条文本提取1-3个关键意思标签，标签用玩家的语言，不用分析师的语言。
- ✓ "引导不清楚"、"不知道下一步做什么"
- ✗ "新手体验问题"（太概括）

**Step 3：合并同义标签**
把表达相同意思的标签合并：
- "不知道玩什么" + "没有目标感" + "不清楚下一步" → 合并为"目标引导不清晰"

**Step 4：聚合为核心维度**
将标签归纳为 4-8 个核心维度，每个维度：
- 有明确的命名（简洁，3-8字）
- 有代表性的原声引用（1-2条）
- 有占比统计（该维度人数/有效回答总数）

**Step 5：输出格式**
```
主题维度          | 占比  | 代表性原声
目标引导不清晰    | 34%  | "不知道下一步该做什么"
玩法重复单调      | 28%  | "感觉一直在重复同样的操作"
付费压力过大      | 19%  | "不付钱很难推进"
美术风格好评      | 15%  | "画风很有特色，很喜欢"
其他零散意见      | 4%   | —
```

### 注意事项
- 先看数据再分类，不要先有分类再往里塞
- 正面和负面都要归纳，不只关注问题
- 占比<5%的零散意见合并为"其他"，不单独列出
- 同一条文本可能涉及多个维度，按主要意思归类

## 二、定量数据解读框架（关键洞察摘要）

适用场景：生成报告顶部的3-5句关键洞察

### 解读优先级（从高到低）

**第一优先：宏观指标的绝对水平判断**

11点量表得分（-5~5）的参考基准：
```
< -2.0   → 极差，玩家强烈不满
-2.0~0   → 偏低，玩家整体负面评价为主
0~1.0    → 中等，玩家评价平平，有一定吸引力
1.0~2.0  → 良好，玩家整体正面评价
> 2.0    → 优秀，玩家高度认可
```

NPS参考基准（游戏行业）：
```
< 0%     → 极差，贬损者多于推荐者
0~20%    → 一般
20~40%   → 良好
> 40%    → 优秀
```

五分量表（1~5）参考基准：
```
< 3.0    → 偏低，需重点关注
3.0~3.5  → 中等
3.5~4.0  → 良好
> 4.0    → 优秀
```

**第二优先：识别异常值和矛盾信号**

常见矛盾模式：
- 整体评分高，但续玩意愿低 → 有吸引力但有留存短板
- NPS高，但整体评分低 → 核心玩家忠诚但口碑未打开
- 美术评分高，玩法评分低 → 画面吸引入坑，内容留不住人
- 亮点选择分散（无一项>40%）→ 没有强核心卖点

**第三优先：分布形态分析**

关注以下分布特征：
- 两极分化（两端高中间低）→ 玩家态度明显分化，需要细分研究
- 极度集中（某一选项>60%）→ 有强共识，是核心信号
- 均匀分散（各选项差距<10%）→ 无明显偏好，可能题目设计问题

**第四优先：与历史数据对比（有历史数据时）**

显著变化阈值：
- 11点量表得分：变化 > 0.3分 → 显著
- NPS：变化 > 5个百分点 → 显著
- 五分量表：变化 > 0.2分 → 显著
- 多选/单选占比：变化 > 5个百分点 → 显著

### 洞察摘要写作规范

**格式：3-5句，每句必须有具体数字支撑**

**结构模板：**
```
第1句：宏观指标总结（整体水平如何，是好是坏）
第2句：最强信号（最显著的亮点或问题是什么）
第3句：关键矛盾或风险（如果有矛盾信号）
第4句：历史对比关键变化（有历史数据时）
第5句：用户画像关键特征（如有分层数据）
```

**示例：**
```
整体评分2.1分（-5~5），NPS 45%，续玩意愿1.8分，整体处于良好水平，
高于同类产品均值。最主要吸引点为黑帮题材（79%）和玩法多样（80%），
题材辨识度高是核心竞争优势。但美术评分（3.2/5）相对偏低，且26%的
玩家提到"引导不清晰"，是当前最主要的体验短板。与上测相比，整体评分
提升0.4分，下载原因中"玩法有趣"占比从52%提升至68%，说明玩法体验优化
效果显著。
```

## 三、用户画像提炼方法

适用场景：有人口统计题、游戏经历题、留存/付费字段时

### 核心分析维度

**维度1：人口统计画像**
- 年龄分布：主力用户年龄段（占比最高的1-2个区间）
- 性别比例：是否有明显偏向
- 职业/收入：是否能推断消费能力

**维度2：游戏行为画像**
- 主玩游戏类型：玩家的游戏品类偏好
- 游戏时长：轻度/中度/重度玩家分布
- 付费习惯：结合LTV和累计充值字段

**维度3：差异化分析（分层比较）**

当有分层变量时（年龄/性别/留存/付费），对每个核心指标做分层对比：
```
对比维度       | 整体  | 25岁以下 | 25-35岁 | 35岁以上
整体评分        | 2.1  | 2.4     | 2.0    | 1.8
NPS            | 45%  | 52%     | 44%    | 38%
主要亮点TOP1    | 题材  | 美术    | 题材   | 题材
```

重点标注差异超过10%的维度，这是最有价值的洞察。

**维度4：高价值用户特征画像**

高留存用户（次日/三日留存=1）的特征：
- 他们更多选择了哪些亮点？
- 他们对哪些模块评分更高？
- 他们的人口统计特征有何不同？

高付费用户（累计充值>0）的特征（同上逻辑）

### 输出格式
```
【用户画像概览】
核心用户：25-34岁男性为主（58%），有中重度游戏经验，付费意愿中等。

【差异化发现】
• 25岁以下用户：对美术评价显著高于整体（+0.4分），更看重画面表现
• 35岁以上用户：NPS低于整体7个百分点，对题材接受度相对较低
• 高留存用户（次日留存）：选择"玩法有趣"的占比（78%）显著高于整体（68%）
  → 初步判断：玩法认可度是留存的关键驱动因素
```

## 四、定性定量融合方法

适用场景：同时有量表题（得分）和开放题/Other填答时

### 触发规则

当以下任一条件满足时，执行融合解读：
1. 某道量表题得分明显偏低（11点量表<0分，五分量表<3.0分）
2. 某道量表题在多测次对比中出现显著下滑（>0.3分）
3. 开放题/Other归纳中出现高频负面主题（>20%）
4. 量表得分与开放题呈现明显矛盾（得分高但开放题负面多）

### 融合解读步骤

**Step 1：锚定量化问题**
先确认量表数据说明了什么问题：
> "玩法满意度评分3.1分（五分量表），属于偏低水平。"

**Step 2：在开放题中寻找印证**
主动扫描开放题/Other填答，找与该量表题相关的文字：
> "开放题中，28%的玩家提到'玩法重复单调'，19%提到'内容太少容易无聊'，
> 与玩法评分偏低高度吻合。"

**Step 3：形成完整结论**
量化结论 + 文字印证 → 合并为一个完整的、有原声支撑的发现：
> "玩法满意度3.1分（偏低），开放题印证主因为：玩法重复单调（28%）和
> 内容量不足（19%），玩家原声如'感觉一直在重复同样的操作'。
> 建议优先评估玩法多样性和内容供给节奏。"

### 输出位置
融合解读内容放在 Step 6 AI分析的"④ 定性定量融合解读"模块，
不嵌入到各题数据区域（各题数据保持纯数据格式）。

### 注意事项
- 量表高分也可以做融合（用开放题的正面原声强化结论）
- 不要强行融合——如果开放题内容与量表题无关，不要牵强关联
- 区分印证（开放题和量表指向同一方向）和矛盾（方向相反，需要特别标注）
