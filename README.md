## 这是什么？

一个专为**游戏用户研究分析师**和**合作部门（发行、策划）**设计的问卷分析 Skill。

上传问卷题目 + 原始数据，AI 自动完成：

- 📊 基础统计（频率、均分、NPS、占比分布）
- 🔀 交叉分析（任意两题 / 题目×留存 / 题目×付费）
- 📝 开放题归纳（主题聚合 + 高频词提炼）
- 📈 历史对比（多轮测试纵向追踪）
- 💡 AI 洞察摘要（数据驱动的关键发现）

## 支持的题型

| 题型 | 处理方式 |
|-----|---------|
| 单选题 | 频次 + 占比，人口统计类不倒序，其他倒序 |
| 多选题 | 选择率 + 频次，倒序排列 |
| 11点量表（0-10分） | 均分-5，结果范围 -5~5 |
| NPS 题 | (推荐者-贬损者) ÷ 总人数 = NPS% |
| 五分量表（1-5分） | 均分 + 每分值占比分布 |
| 填空题 | 内容类→主题归纳+高频词；联系方式类→跳过 |

## 怎么用？

### 方式一：发飞书链接（推荐）
```
帮我分析这个问卷
题目：https://xxx.feishu.cn/sheets/xxx
数据：[附件]
```
> 需管理员开通飞书 MCP，在搜索栏搜索「飞书 MCP」查看开通引导

### 方式二：发本地文件
```
帮我分析这个问卷
[附件：问卷题目.xlsx]
[附件：原始数据.xlsx]
```

### 不知道怎么开始？
直接说：**「你好，帮我分析问卷」**，AI 会一步步引导你。

## 核心功能详解

### 📊 自动剔除无效样本
答题时长 < 60秒的问卷自动剔除，报告开头告知剔除数量。

### 🔀 交叉分析
```
帮我交叉分析第3题和第8题
帮我看下年龄和整体评分的关系
帮我分析下载原因和次日留存的关系
```
执行前 AI 会二次确认题目，避免题号记错。

### 📈 历史对比
AI 自动记忆每次分析的核心数据，下次分析同一项目时：
```
帮我分析W3这次的数据（附件）
```
AI 自动识别历史记录，询问是否加入对比，自动标注 ▲▼ 变化。

### 💡 AI 洞察摘要
每次分析完自动输出：
- 关键数据洞察（3-5句，数据驱动）
- 用户分层画像
- 问题诊断与根因
- 定性定量融合解读
- 结论与可操作建议
